# scoop-bucket

Scoop bucket for [pfwd](https://github.com/hoanghero125/pfwd), the VS Code Ports panel for any terminal: it detects the ports listening on an SSH host and forwards them to localhost.

```powershell
scoop bucket add pfwd https://github.com/hoanghero125/scoop-bucket
scoop install pfwd/pfwd
```

GoReleaser updates `bucket/pfwd.json` on every pfwd release. Open issues in the [pfwd repository](https://github.com/hoanghero125/pfwd/issues), not here.
